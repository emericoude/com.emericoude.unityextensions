# Emeric's Tools for Unity

- Emericoude.Attributes**: a series of useful attributes to improve your inspector fields.
- Emericoude.Cinemachine: Cinemachine utilities.
- Emericoude.Collections: Custom collections (e.g. LootTable).
- Emericoude.Feedback: Components related to adding 'Juice' or game feel.
- Emericoude.Framework: Some framework scripts (such as different types of singletons).
- Emericoude.Helpers: Extension scripts that span a large variety of utilities.
- Emericoude.Input: Scripts relating to Unity's new Input System, such as custom interactions.
- Emericoude.Pawns: A player-pawn-ai controller framework inspired by Unreal Engines'.
- Emericoude.Physics: Custom physics components.
- Emericoude.StateMachine: A custom (hierarchical) state machine framework.
- Emericoude.UI: Components for Canvas (NOT UI TOOLKIT).
