# XML Documentation Cheatsheet

- [Microsoft's Recommended Tags](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/xmldoc/recommended-tags)
- \<b/> = line return
- \<para/> = paragraph return
- Escape characters (as in characters you can't write normally in XML)
  - \" :: \&quot; 
  - \' :: \&apos;
  - \< :: \&lt;
  - \> :: \&gt;
  - \& :: \&amp;
